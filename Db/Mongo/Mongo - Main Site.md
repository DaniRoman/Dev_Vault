## exec()

`exec()` se usa para **ejecutar explícitamente una query de Mongoose** y obtener una **Promise real**.  
`find()`, `findById()`, etc. devuelven una query; `create()` no.

Mini regla:
- `find`, `findOne`, `findById` → puede llevar `exec()`
- `create` → no lleva `exec()`
